# Fraud Detection in Financial Transactions

This project analyzes synthetic mobile money transaction data to detect fraudulent activities using SQL, Power BI, and DAX. It provides actionable insights to identify fraud patterns, high-risk users, and transaction anomalies.

#  Tools & Technologies

- SQL (MySQL) – For data exploration, pattern detection, and fraud rule logic
- Power BI – For interactive dashboards, dynamic drillthrough, and storytelling
- DAX – For dynamic measures and KPIs
- PowerPoint – Final presentation summary

# Key Features
- Fraud type breakdown (Transfer, Cash Out, etc.)
- Time-step based anomaly analysis
- Drillthrough to inspect flagged transactions
- High-risk user identification using logic-based SQL
- Dynamic KPIs using slicers (fraud count, type, flag status)
